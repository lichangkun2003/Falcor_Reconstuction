# 像素视锥前向调试

关闭 `Enable Reconstruction`，加载已有重建，选择 `Draw Mode = Default`。
勾选 `Pixel Frustum (forward preview)` 使用像素视锥；取消勾选使用原有随机射线 DDA。
切换会通知下游 AccumulatePass 重置累计。勾选 `Use ReferenceCamera` 可以在训练相机下比较。

面积现在通过实际轮廓的解析积分计算，`Coverage Directions` 已移除。
视锥路径不使用像素 jitter，静止相机下重复帧结果一致。

## 前向流程

- 复用当前相机的无抖动 VP / 逆 VP、输出分辨率和近远平面。
- 在相机深度上分段。用整段视锥的八个顶点构建 cell 包围范围，
  再用六个视锥平面保守剔除 cell。
  与相机近裁剪平面相交或接触的整个 cell 直接跳过，不计算极近体素的部分覆盖。
- 按 cell 中心深度给每个 cell 分配唯一深度段；段内按中心深度、voxel ID 排序。
  分段枚举范围扩展一个 cell 的半深度，保留视锥擦过 cell 边缘的情况。
- 查询空间索引和 occupied，仅对非空候选计算面积。
  四角射线每像素只构造一次，深度段复用其位置和斜率。
  每次扫描保留最近的四个候选并排序；超过容量时继续分批，不丢弃候选。
  用完整椭球与像素侧平面的分离测试保守排除零覆盖。
  四角射线在缩小的体素内均穿过椭球内部时直接返回覆盖率 1；
  单精度判断保留误差裕量，不确定的情况回退到双精度解析面积。
- 将椭球变换为单位球，用所属 cell 的六个平面、相机近远平面以及像素四个侧面截断。
  这是三维交集的投影；不使用完整椭球与体素各自投影的二维交集近似。
- 解析构造球的视角轮廓圆、球与裁剪面相交的圆、裁剪面两两相交的线段。
  按剩余约束及面朝向切分、筛选真正位于投影边界的弧和线段。
- 使用格林公式 `A = 1/2 ∮(x dy - y dx)` 累加定向边界积分。
  透视投影的圆弧是有理三角曲线，使用解析原函数，处理椭圆、双曲线和抛物线退化情形。
  直线段直接使用端点叉积。无需将曲线采样成多边形，也不按像素面积采样射线。
- 像素四角的射线均命中截断实体时，利用其投影的凸性直接返回覆盖率 1。
  输入几何及输出覆盖率仍为 float；交点、朝向判断和积分使用 double。
  结果存在输入精度、容差和浮点数值误差，不声称任意退化输入下的无限精度。
- 以 `effectiveAlpha = c * opacity` 合成 SH 颜色和透射率，最后加入背景。
  每个像素的 `T` 从 1 开始，逐体素更新为 `T *= 1 - effectiveAlpha`。
  `T` 小于等于现有阈值时停止整个视锥遍历；提前终止和穿出场景都加入 `T * envmap`。
  只有已加载且启用的 envmap 才有背景贡献；否则背景为零，视锥路径不使用 clearColor。
  SH 和环境背景使用像素中心方向；不计算前后覆盖相关性。

这是用于检查覆盖前向的版本：小批量排序并继续处理溢出的候选，没有沿用
16 个 hard-hit 的贡献上限，但在透射率达到现有阈值时提前终止。
尚未使用占据层级，深层半透明几何和较宽像素足迹会增加遍历成本。
双精度级数的固定循环已展开，避免运行时循环除法；仍保持解析轮廓和双精度积分。
整帧性能还依赖空区域遍历和轮廓像素数量；消费级 GPU 的双精度吞吐也会影响速度。

训练依然使用原有射线前向和 PathRecord，不写入尚无匹配反向的覆盖记录。
TopologyDebug 也继续使用原有 DDA。mode 0/1 行为和默认模式保持原设置；
完整 mode 2 训练及覆盖率导数需另行接入。

## 验证

配置 `VOXEL_RECONSTRUCTION_BUILD_FRUSTUM_TESTS=ON`，构建 `VoxelFrustumTests`。
该无窗口 D3D12 测试验证解析面积、cell 截断、细结构、旋转、透视和近面截断，
增加像素圆弧裁剪、体素轮廓线段、相机近处双曲线/抛物线，以及投影重叠但三维深度不交叠的情况，
并运行生产前向 shader 检查候选遍历、深度次序、唯一合成和背景透射率，
以及与独立密集射线积分对照的斜视透视相机结果。源码测试运行时需设置 `FALCOR_DEVMODE=1`。
另外比较高分辨率下快速路径与纯解析路径的逐像素输出，检查旋转和体素截断，
并验证每段超过批容量的深度排序和透射率。GPU 时间戳报告同场景两条路径的耗时；
测试小场景的计时不代表实际数据集或训练性能。

弧与线段面积积分的背景推导可参考 [Geometric Tools](https://www.geometrictools.com/Documentation/AreaIntersectingEllipses.pdf)。
本实现还处理三维裁剪和透视投影，不是直接求两个二维椭圆交集。
